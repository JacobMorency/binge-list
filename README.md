# BingeList 🍿

A simple Movie and TV Show watchlist and tracker that allows users to keep track of the movies and TV shows that they've seen or want to watch.

## Live Demo Link
[BingeList](https://thebingelist.vercel.app/)

## 🔥 Features
- 🔎 Search and filter content
- ⭐ Add content to favorites, watchlist, and watched list
- 🔐 Supabase Auth for login
- 💻 Supabase backend

## 🚀 Tech Stack
[Next.js](https://nextjs.org)
[Supabase](https://supabase.com)
[TailwindCSS](https://tailwindcss.com)
[TypeScript](https://www.typescriptlang.org/)
